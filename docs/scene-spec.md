# FrameLab Scene Spec 1.0

The Scene Spec is the versioned interchange format for structured scenes. It is designed to be generated by an external workflow (for example, n8n + Groq), reviewed in FrameLab, and then rendered by the existing editor pipeline.

## Design principles

- The LLM produces data, never FFmpeg commands or renderer instructions.
- FrameLab validates the specification before importing it.
- Layout and content are separate: a template defines placement and typography; blocks provide the content.
- Coordinates use percentages from 0 to 100, measured from the top-left of the 9:16 canvas.
- Times are milliseconds.
- Unknown versions must be rejected instead of being guessed.

## Top-level structure

- `version`: required schema version. Current version: `1.0`.
- `project`: optional metadata such as title, languages and aspect ratio.
- `scenes`: one or more scenes.

A scene contains an ID, name, layout, duration and one or more blocks. Blocks represent visible text elements and may include an icon token, an anchor, timing offset, position, typography and alignment.

## Supported layout identifiers

- `category-list`
- `question-answer`
- `before-after`
- `title-icon-caption`
- `freeform`

## Example

```json
{
  "version": "1.0",
  "project": {
    "title": "English in Context",
    "language": ["en", "pt-BR"],
    "aspectRatio": "9:16"
  },
  "scenes": [
    {
      "id": "scene-01",
      "name": "Question and answer",
      "layout": "question-answer",
      "durationMs": 6000,
      "blocks": [
        {
          "id": "question",
          "role": "question",
          "text": "What's the difference?",
          "icon": "❓",
          "x": 50,
          "y": 38,
          "fontSize": 62,
          "color": "#ffffff",
          "align": "center"
        },
        {
          "id": "answer",
          "role": "answer",
          "text": "It depends on the context.",
          "icon": "💡",
          "startOffsetMs": 900,
          "x": 50,
          "y": 61,
          "fontSize": 46,
          "color": "#65d6c0",
          "align": "center"
        }
      ]
    }
  ]
}
```

## Current editor support

The first Scene Spec integration imports and exports graphic blocks as Motion Graphics. It currently applies text, icon token, position, duration, font size, color and alignment.

The schema already reserves optional fields for captions, audio and character references so that future versions can add these capabilities without changing the overall scene envelope. These metadata fields are not yet applied by the editor importer; FrameLab displays a notice when such metadata is present.

See [scene-spec.schema.json](./scene-spec.schema.json) for the machine-readable JSON Schema.

## Lucide SVG icons

Scene blocks may optionally define:

- `iconName`: a supported Lucide icon component name, such as `Eye` or `Lightbulb`.
- `iconAnchor`: `left`, `right`, `top` or `bottom`; the icon is positioned relative to the text inside the same motion block.
- `iconSize`: icon size in design pixels (12–180).
- `iconColor`: SVG stroke color.

The editor's Lucide library currently provides a curated searchable set of icons. Selecting an icon binds it to the text block, so dragging the text moves the icon with it. These properties are preserved by Scene Spec import/export.

**Rendering limitation in this iteration:** Lucide SVGs are displayed in the editor preview, but the current native MP4 export contract only accepts text overlays. MP4 rasterization of SVG icons is a separate renderer integration and is not silently represented as complete.
